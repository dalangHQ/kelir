┌─────────────────────────────────────────────────────────────────────────────┐
│                       STORAGE & FILESYSTEM ARCHITECTURE                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. EROFS READ-ONLY ROOTFS (virtio-blk):                                     │
│    - Stripped base system (Python, Node, Rust, Bash) pre-baked into EROFS.  │
│    - Cold-mounted as block device. Zero tarball decompression.              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2. COPY-ON-WRITE SCRATCHPAD (overlayfs over sparse host file):              │
│    - Base host workspace mounted STRICTLY READ-ONLY.                        │
│    - overlayfs upperdir maps a sparse host-backed file via virtio-blk.      │
│    - Writes hit sparse disk blocks, never guest RAM: no guest OOM on        │
│      large writes, host footprint independent of write volume.              │
│    - Instant Revert: truncate the sparse backing file or punch holes        │
│      in <1ms. Host SSD blocks are reclaimed, not a RAM layer dropped.       │
│    - Rollback page purge: FALLOC_FL_PUNCH_HOLE + posix_fadvise              │
│      (POSIX_FADV_DONTNEED) purges the host kernel dirty page cache.         │
│    - Ephemeral scratch device: dedicated virtio-blk sparse disk at /tmp     │
│      and /var/cache, discarded on teardown without reconciliation; keeps    │
│      high-churn caches out of workspace git diffs and whiteout tracking.    │
│ 3. THE SUCCESS PATH RECONCILER (extension-based reconcile):                 │
│    - Storage-plane sync: stages upperdir into .kelir-staging-<nonce>.       │
│    - Executes atomic directory exchange (renameat2 / RENAME_EXCHANGE).      │
│    - Zero filesystem corruption; Git commits stay ordinary guest runs.      │
│    - Host inode resolution via openat2(RESOLVE_BENEATH|RESOLVE_NO_MAGIC-    │
│      LINKS); S_ISUID/S_ISGID stripped on write, create, chmod.              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4. UID / GID ID-MAPPING (idmap):                                            │
│    - Translates guest root (UID 0) and node (UID 1000) to host geteuid().   │
│    - Prevents files written by microVM from requiring host `sudo` to edit.  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 5. SHARED HOST PACKAGE CACHES (virtio-fs read-only mounts):                 │
│    - Mounts host ~/.npm, ~/.cache/pip, ~/.cargo/registry into guest.        │
│    - Package installs drop from 2 minutes to <3 seconds on cold microVMs.   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 6. SYNTHETIC FUSE INODES (RAM-Only Virtual Files):                          │
│    - Injects virtual configurations (.env, .gitconfig) directly into VFS.   │
│    - Served from host memory; physically DOES NOT EXIST on host SSD.        │
├─────────────────────────────────────────────────────────────────────────────┤
│ 7. SLIDING-WINDOW REPLACEMENT OVER FUSE READ BUFFERS:                       │
│    - Intercepts FUSE read(); runs sliding-window chunk pattern scanner.     │
│    - Fixed-width byte replacement on-the-fly; zero full-file RAM buffering. │
├─────────────────────────────────────────────────────────────────────────────┤
│ 8. SECONDARY READ-ONLY IMAGE MOUNTS:                                        │
│    - Host-grafted FUSE subtrees for squashfs/EROFS pack images.             │
├─────────────────────────────────────────────────────────────────────────────┤
│ 9. HOST INODE LOCK BROKER (Cross-VM Concurrency):                           │
│    - Intercepts FUSE SETLK / SETLKW; delegates to host OS advisory locks.   │
│    - Maps virtual guest inodes to host physical inodes to avoid collisions. │
├─────────────────────────────────────────────────────────────────────────────┤
│ 10. HOST STATE ROOT (~/.kelir/) + STORAGE CATALOG (06):                     │
│    - catalog.db: embedded SQLite (WAL), 3 tables only: sessions,            │
│      cas_leases, schema_version. No resident daemon; every process opens    │
│      the file directly. WAL + busy_timeout 5000ms; writers serialize via    │
│      busy handlers, readers proceed concurrently.                           │
│    - sessions: DETACHED sessions only (session_id, status, pids,            │
│      rootfs_hash, expires_at); the sessions row carries the detached-       │
│      runner lease (runner refreshes expires_at every 30s; expiry            │
│      triggers a janitor sweep on startup).                                  │
│    - Lockless ephemeral path: detached=false sessions bypass catalog.db     │
│      entirely: zero SQLite transactions or rows; ephemeral state stays      │
│      resident in host process memory, anchored to parent lifetime.          │
│    - Runner signaling uses pidfd_open/pidfd_send_signal exclusively,        │
│      verified against host_boot_id + proc start_time; stale rows with       │
│      recycled PIDs abort delivery.                                          │
│    - Ephemeral reaping: Linux pidfd + OS death signals drive zero-delay     │
│      reaping (no lease polling; detached sessions use the watchdog poll).   │
│    - cas_leases: blob_hash, holder_pid, expires_at_unix (30s TTL);          │
│      blobs with zero unexpired leases are pruned without locks.             │
│    - Schema evolution drops ephemeral tables; immutable CAS files stay      │
│      intact.                                                                │
│    - cas/blobs/blake3_<hash>: immutable layer storage (kelir-pack output).  │
│    - sessions/<id>/: ephemeral runtime state, logs/ + index.bin, relay.sock,│
│      owner.pid. Lineage is NOT in SQLite: snapshot manifests immutably      │
│      record parent_digest; lineage walks the CAS manifest DAG.              │
│    - Quotas: allocated_bytes / allocated_inodes atomics gate on_fs_write    │
│      and FUSE mknod/create/mkdir; over budget fails synchronously ENOSPC,   │
│      zero disk writes on rejection.                                         │
│    - statfs returns remaining upperdir quota in O(1); quotas evaluate       │
│      against the sparse upperdir delta only; the lowerdir host workspace    │
│      incurs zero statfs traversal (zero-crawl baseline).                    │
└─────────────────────────────────────────────────────────────────────────────┘

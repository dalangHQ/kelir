Fork isolation: Inline trap closures and stateless plugins inherit CoW state automatically;
specialized host state branching overrides `fork_state()`, unclonable resources veto via `VetoEvent::Fork`.
Typed enum compilation: LifecycleEvent, Ring, and TrapFilter values are checked
at compile time in Rust and TypeScript and at import time in Python; string
event names are not accepted dispatch keys in any language.

are directly accessible on Session; optional domain plugins attach via extensions.

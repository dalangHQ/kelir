                             [CONNECTION PARKING]
                             Host-terminates client TCP; buffers up to 64KB initial data;
                             wakes microVM and splices duplex stream across stream
                             mux 0x0001, kind L4_FORWARD 0x0005. The carrier is
                             L4-only by default: no sniff, no L7 parsing, no HTTP
                             rewriting in the supervisor, TLS byte-for-byte.
                             L7 only when the builder mounts a NetInterposer with
                             an L7 scope; the interposer never terminates TLS.
                             L7 stages are db-proxy and wire-ingress only.
                             Default vault path: the guest fetches a scoped token
                             and presents it; no host TLS termination, no CA
                             injection. L7 rewriting, if needed, is via an optional
                             external sidecar only.
                             Permitted UDP egress uses endpoint-independent (Full Cone)
                             NAT: one host UDP socket per guest source port, external
                             source port preserved for STUN, WebRTC, Tailscale.
                             Streaming L7 payloads keep a MAX_PLACEHOLDER_LEN - 1
                             carryover window; frame reassembly eliminates token
                             fragmentation across TCP boundaries; HTTP/2 streams
                             normalize into framed request buffers before scan.
                             Port-forward host binds set SO_REUSEADDR + SO_REUSEPORT;
                             SO_LINGER zero forces instant TCP RST on teardown,
                             eliminating TIME_WAIT exhaustion across rapid iterations.
                             Explicit host_port bind failure returns
                             Err(WireError::PortOccupied); a bootstrap bind failure
                             aborts launch before the first vCPU cycle, with no
                             silent ephemeral fallback. Teardown verifies listener
                             release before Stopped; the management API reports a
                             port published only after successful bind.
                             UDP socket reaper: guest source ports map into an
                             indexed slab, 1024-entry hard cap; cap exhausted ->
                             oldest idle socket reclaimed first; idle 30s with
                             zero ingress/egress -> close; a fresh packet on a
                             reclaimed port reopens an ephemeral host socket.
                             Rollback closes every host-side socket; guest TCP
                             sees RST/FIN, subsequent sends fail ECONNRESET;
                             UDP NAT slab entries are dropped; sockets are not
                             restored from snapshots.

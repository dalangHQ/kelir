  - Invariants and policy (vfs)
    - Reconciler
      - see: artifacts/code/reconciler.rs
      - Pure stdlib implementation: zero external crate dependencies
      - session.fs.reconcile() is a pure storage-plane operation
      - Lifecycle hook bindings
        - on_pre_commit flushes in-flight FUSE buffers
        - on_post_commit triggers sibling swap (.tmp.<nonce>) into host workspace
      - Scans tmpfs upperdir diffs only; base files remain untouched
      - Overlayfs char devices (st_rdev == 0) trigger host file unlinks using openat2
      - Unlinks enforced strictly within host workspace root; escapes fail closed
      - Atomic sibling file swap (.tmp.<nonce>) and parent fsync
      - Whiteout problem
        - Deleted files become char devices with major/minor 0/0 (mknod c 0 0)
        - Deleted or shadowed directories carry xattr trusted.overlay.opaque="y"
        - Direct upperdir copy writes broken device nodes and resurrects files
      - CommitStats counters
        - files_changed: count of modified or newly created files
        - whiteouts_resolved: count of file and directory whiteouts handled
      - Reconciler coverage: TBD
        - Symlinks
        - Hardlinks
        - Non-regular, non-dir file types
        - xattrs and ACLs
        - Mode, uid, gid, mtime
        - Sparse files
        - Deleted-directory subtree walk
        - Reconcile-during-write
        - Partial-reconcile crash recovery
        - Directory fsync
        - Host-side deletion scope
      - FUSE low-level binding: raw kernel ABI structs; bans fuser and fuse3
    - Synthetic FUSE inodes
      - Architecture (synthetic inodes): see: artifacts/diagrams/storage-architecture.txt
      - VfsInodeAttr mode: 0o400 honored strictly; no permission fallback
      - Dynamic hash formula: BLAKE3(path || generation_counter || mode)
    - In-flight read masking
      - Flow: see: 05-storage-plane.md#Sliding-window-replacement-over-FUSE-read-buffers
      - Format-preserving masking (FPA) executes via synthetic FUSE inode generator
      - Generates format-valid synthetic content before guest read calls
      - Example patterns: sk_live_, AKIA, BEGIN PRIVATE KEY blocks
      - see: artifacts/examples/autonomous-swe-agent.ts (vfs.maskRead)
    - UID/GID idmap: see: 05-storage-plane.md#Virtual-ID-remapping
    - Shared host package caches: see: artifacts/diagrams/storage-architecture.txt
    - Snoop plane
      - Invariant: a snoop observation reflects the producing process, not a
        kernel flusher
        - Achieved by bypassing guest page cache on snooped paths; mechanism
          lives in plugin-vfs
      - Invariant: no host-side hook failure can leave the guest thread in D
        state
        - Achieved by a guaranteed FUSE reply from every user callback;
          mechanism lives in plugin-vfs
      - Consumer: Oracle.ingest_harness_event; see: 08-epistemic.md#Oracle
      - Producing process metadata is resolved via HandlerCtx extension slots

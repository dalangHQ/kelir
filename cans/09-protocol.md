- Protocol
  - Control channel
    - virtio-vsock port 5252: unified multiplexed transport
    - Binary framing isolates sub-protocols via channel_id
      - Channel 0: Core hypervisor lifecycle and trap control
      - Channel 1: Dynamic L4 stream forwarding
      - Channels 2-65535: Dynamically registered extension endpoints
      - Channel kinds map via explicit registration: see: #Channel-registration
    - Eliminates multi-port socket allocation and port collisions
  - Trap fast-path
    - Step sequence and per-step mechanics: see: artifacts/diagrams/trap-flow.txt
    - Three-tier gate pipeline
      - Gate 1: guest in-kernel BPF allowlist returns for harmless tools
      - Gate 2: native MountScope/schema eval (0 FFI)
      - Gate 3: trap handler dispatch through FFI trampoline on match only
      - Gate latency budgets: see: 02-plugin-model.md#Latency-ceiling
      - Filter invariants: see: 02-plugin-model.md#Filter-before-FFI-gate
      - A single trap-on-every-syscall design adds ~µs per fork/exec at
        toolchain scale; the allowlist exists to pay that cost only where
        policy is possible
      - cgroup v2 freezer closes check-to-use race without ptrace latency
      - process_vm_readv captures exact memory without thread attachment
      - A frozen inspection is still blind to what the loader *will* do;
        the linker audit exists to make the inspection meaningful
    - Measurement rule
      - Syscall trap resolves target binaries by kernel (st_dev, st_ino)
      - Prevents path confusion across nested namespaces, chroots, and crun roots
      - In-kernel BPF denies CLONE_NEWUSER unless explicitly allowed in MountScope
      - Agents cannot hide execution by spawning unprivileged child containers
      - ELF is read from disk at trap time: /proc/$PID/maps still describes
        the pre-exec image and cannot be trusted
      - Scans /proc/$PID/auxv, envp, and PT_INTERP before cgroup unfreeze
    - Flow diagram: see: artifacts/diagrams/trap-flow.txt
    - Fast-path policy: TBD
  - Wire framing
    - see: artifacts/code/wire-protocol.rs
    - Layout (header offsets, magic, version): see: artifacts/code/wire-protocol.rs
    - Framing invariants
      - Frame fields follow strict Little-Endian byte order
      - Maximum single frame payload capped at 64KB
      - Payloads exceeding 64KB split across frames using FLAG_CONTINUATION
      - Monotonic 64-bit sequence transmitted natively without word splitting
      - Codec reads exact 24-byte FrameHeader; payload decodes directly

  - Wire messages
    - see: artifacts/code/messages.rs
    - Message set and payload fields: see: artifacts/code/messages.rs
    - Hook binding: one hook per message
      - Contract: see: 02-plugin-model.md#KelirPlugin-trait
    - TrapAction-method-mapping
      - TrapAction::Allow: c.resume()
      - TrapAction::Deny: c.deny(exit_code, diagnostic_payload)
      - TrapAction::Rewrite: c.rewrite(target_mutation)
      - TrapAction::Yield: c.yield(checkpoint_id)
      - TrapAction::Abort: c.abort(exit_code, reason)
      - TrapAction::Hold: c.hold(duration_ms)
      - TrapAction::Custom: c.custom(name, cbor_payload)
    - Hold wire contract
      - Host halts vCPU execution and drops RAM footprint via suspend primitive
      - Host releases suspension when the hold duration elapses
    - Custom dispatch contract
      - Registration: builder.register_custom_action(name, schema, handler)
      - Wire Custom carries the CBOR payload only; the name resolves at SDK registration
      - Unknown name at trap time fails with EUnknownAction
      - Registration after boot() fails with EConfig
    - Action invariants: see: artifacts/code/messages.rs
  - Channel registration
    - LifecycleCtx.register_channel(kind, handler) assigns a u16 channel kind
    - kind stable per session; collision aborts boot with EChannelConflict
    - kind 0 is core-reserved; registering kind 0 aborts with EChannelReserved
    - Core dispatches HostToGuest::ChannelData { kind, .. } to the handler
    - Unknown kinds abort delivery with EUnknownChannel
    - SDK channel surface: see: 03-sdk-architecture.md#Language-surfaces
  - Env injection
    - Workload environment variables, registers, and execution paths remain
      immutable under Allow verdicts
    - State mutations require explicit Rewrite with validated disjoint keys

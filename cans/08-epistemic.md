- Verification & Hardware Telemetry
  - Scope
    - Boundary specification; not a runtime subsystem
    - Core owns facts, never judgments
      - Facts: TrapEvent, ExecutionReceipt, CausalDelta (struct)
      - Core owns physical hardware telemetry: registers, memory diffs, counters
    - Judgment is defined in external userland orchestration layers
      - Evaluators consume raw execution receipts independently of core
    - Axiom enforcement: see: 01-architecture.md#Axiomatic-foundations
  - Oracle
    - Evaluator contract defined in orchestrator SDK layer, outside kelir-core
    - Consumes physical execution receipts to evaluate workload correctness
  - Primitive vs derived telemetry
    - Telemetry decision test
      - Single read API, hardware boundary, no policy → primitive, core-owned
      - Computed from primitives, policy-bearing → derived, plugin-owned
      - A new derived metric is a plugin or Oracle change, never a core method
    - Default posture: per-exec, per-trap, per-receipt signals on; per-syscall,
      per-request, per-page signals off until enabled per config
    - Boundaries
      - Primitive set: see: 01-architecture.md#Core-invariants
      - CausalDelta: see: #Causal-delta
      - Merkle chain: see: plugins/ledger.md#Merkle-WAL
      - OpenTelemetry spans: see: plugins/ledger.md#OpenTelemetry
      - Oracle analyses: consumer's Oracle impl
  - Execution receipts
    - see: artifacts/code/execution-receipt.rs
    - End-to-end instruction-counter and dirty-byte hardware attribution
    - Cryptographic provenance chain: model generation -> trap -> receipt
    - Granular hardware telemetry: micro-level execution telemetry per process
    - Emitted per executed process, at the trap/exit boundary
    - Assertion form: receipts are compared as values, not as hashes of host
      state; the canonical assertion is a per-field comparison
    - Byte-not-page reason: see: 01-architecture.md#SnapshotDescriptor.dirty-bytes
    - Population: per ReceiptConfig; opt-in fields not enabled are absent
      (Option), never 0
      - retired_instructions: sampled from host vCPU thread via perf_event_open
      - Apple Silicon: queried via native Mach thread instruction counters
      - Eliminates cross-architecture dirty-page and wall-clock variance
      - Opt-in: syscall_count
      - dirty_bytes is always populated: zero is a real measurement, not an
        absent value
    - binary_blake3 canonical form: TBD
    - Receipt accounting: TBD
      - syscall_count counting rule
      - egress_bytes observation point
      - wall_clock_ns across suspend
      - exit_code under Rewrite
      - dirty_bytes under fork
      - Sub-microsecond phase spans: trap_ingress_ns, ffi_hop_ns, policy_ns
    - binary_blake3 cache: keyed on (inode, size, mtime_ns); one hash per
      binary identity, not per exec
    - Receipt ownership
      - kelir-core generates and holds at trap/exit boundary
      - c.receipt() is the single read API on HandlerCtx
  - Causal delta
    - see: artifacts/code/causal-delta.rs
    - Definition: Δ = S_A − S_B between two checkpoint descriptors
    - Delta fields: see: artifacts/code/causal-delta.rs
    - State diff aggregation: CausalDelta aggregates net physical diffs
    - Merkle root chaining links granular receipts to state diffs
    - Tracks physical page deltas, modified inodes, and process lineage
    - L7 protocol telemetry lives in plugin-wire, isolated from core structs
    - Type ownership
      - Struct is a shared context type; it lives in kelir-interface next to
        ExecutionReceipt
      - Computation is derived: see: plugins/ledger.md#compute-causal-delta-engine
    - This split follows the primitive-vs-derived rule: type is primitive,
      computation is derived
  - Three-tier evidence verification model
    - see: artifacts/diagrams/truth-hierarchy.txt
    - Tier evidence per tier: see: artifacts/diagrams/truth-hierarchy.txt
    - Tier 1 Hardware/Hypervisor Sampling
      - PMU retired instructions, host TSC deltas, dirty-page bitmaps
      - Kernel register state
    - Tier 2 Boundary Paravirtual Intercepts
      - FUSE write journals, TAP L2/L4 frame counters
      - Sanitized PTY stream digests
    - Tier 3 Guest Userland Self-Reporting
      - Unverified harness stdout/stderr, guest status JSON
    - Selection rule
      - Claim must resist forgery by guest code → Tier 1
      - Claim about a public, versioned contract → Tier 2
      - Claim about harness-internal state with no wire surface → Tier 3
    - Degradation rule
      - A higher-tier claim never falls back to a lower-tier signal
      - Missing Tier 1 evidence is a denial, not a Tier 3 downgrade
      - Rationale: silent downgrade is exactly the harness self-report failure
        this tier scheme exists to prevent
    - Consumer of Tier 3: Oracle.ingest_harness_event; see: #Oracle

  - Step evaluation loop
    - Orchestrators execute unmodified agent binaries
    - Checkpoint descriptors are retained in userland orchestrator state
    - Post-step verification compares physical receipts against pre-step states
    - StepSlot semantics: TBD
      - Stack vs single slot

    - Typical wiring
      - before("*"): checkpoint + analyzeIntent; deny or resume
      - after("*"): read receipt; rollback on post-condition violation

    - Trace hooks (.trace()) measure exact nanosecond overhead across phases
    - Tracks trap ingress, FFI crossing, policy evaluation, and verdict dispatch
    - Zero-allocation timings pipe directly to receipts and OTel spans
